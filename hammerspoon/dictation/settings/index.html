General

Hotkeys and on-screen feedback.

Hotkeys

Click a shortcut, then press the new key combination. Esc cancels.

While dictating

Recording dot, timer and level meter near the bottom of the screen.
Shows an approximate transcript while you speak. Uses the GPU continuously while recording.
Messages such as "Nothing heard". When off, they go to the Hammerspoon console.

Cleanup

How the transcript is tidied before it's pasted.

Mode

Off: raw Whisper text. Quick: removes fillers and repeats instantly. Full: Quick, then a local LLM fixes false starts and punctuation.
Shorter dictations skip the LLM and paste almost instantly.
If the model takes longer, the Quick cleanup text is pasted instead.
Names and technical terms to spell correctly, one per line. The first 12 also guide Whisper.

Transcription

Speech-to-text with whisper.cpp.

Whisper

Bigger models are more accurate but slower. Downloads come from the whisper.cpp repository on Hugging Face, are checked against pinned checksums, and are saved in . Select a downloaded model, then Save.
The selected model only understands English, so this has no effect. Choose a model without "English only" for other languages.
